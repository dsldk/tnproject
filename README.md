# Tekstnets projektskabelon

Mappen project-layout udgør en projektskabelon som kan kopieres til brug i nye
projekter. Det kan gøres ved at klone dette repositorium eller downloade det som
zip-arkiv. Når du har arkivet kopierer du  

```
cp -r project-layout /sti/til/mappe/projektnavn
```

## Indhold

```
project-layout/
├── data/
│   ├── accounts/
│   │   └── nn-n_example-text/
│   │       └── index.md
│   ├── introductions/
│   │   └── nn-n_example-text/
│   │       └── index.md
│   ├── notes/
│   │   └── nn-n_example-text.toml
│   ├── persons/
│   │   └── persons.toml
│   └── texts/
│       └── nn-n_example-text/
│           └── nn-n_example-text.xml
├── docs/
├── .gitignore
└── README.md
```
